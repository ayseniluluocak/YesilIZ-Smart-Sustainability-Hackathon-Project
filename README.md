# YesilIZ-Smart-Sustainability-Hackathon-Project
GDG Bursa Hackathon 2026 Project

This project is a smart city platform concept developed within the scope of the **GDG Bursa Tent Camp Hackathon 2026**. The project aims to bring local governments and citizens together with a focus on sustainability.

# Problem Definition
* **Lack of Structural Environmental Data:** The inability to instantly detect environmental violations in cities and the resulting delays in solutions.
* **Dispersed Reporting Mechanisms:** The inefficiency of existing complaint channels and the difficulty in citizen participation.

# Solution and Value Proposition
YeşilIZ is an end-to-end smart platform where citizens can report environmental problems such as illegal logging, water leaks, and uncontrolled dumping with photos and location information.

* **AI Analysis:** The incoming report images are analyzed by artificial intelligence and assigned type, accuracy, and priority scores. 
* **Citizen Participation & Incentive:** Users receive non-cash "Green Points" for verified reports. These points can be used for discounts on public transportation and municipal events.

# Technical Architecture and Security (Planned)
* **Data Security:** Authentication is done through e-Government API integration, but GDPR compliance is ensured by using Anonymous User ID within the system.
* **Abuse Prevention:** To prevent fraudulent reports, a daily maximum limit of 15 reports and GPS-based location tracking have been integrated.

# Project Status
This repository contains the conceptual design, business model, and system architecture of the project, developed in a limited time during the **GDG Bursa 2026 Hackathon**. You can access the detailed presentation file from within the repository.
